# Triage labels

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate the report |
| `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | Scoped and ready for agent implementation with independent review |
| `ready-for-human` | Requires human judgment or implementation |
| `wontfix` | Declined with an explanation |

Agents do not merge pull requests. The owner makes the final decision.
